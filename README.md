# dascpt1.github.io

Personal site and project portfolio, served via GitHub Pages at
https://dascpt1.github.io/

## Editing

Plain HTML/CSS, no build step - edit `index.html` and `style.css` directly, then
commit and push. Changes go live within a minute or two of pushing to `master`.

Things to fill in:

- Replace the placeholder project cards in `index.html` with real projects (name,
  description, link to the GitHub repo).
- Fill in the About section.
- Update the contact email in the `mailto:` link.

## Local preview

Open `index.html` directly in a browser, or use the VS Code "Live Server" extension
for auto-reload while editing.
